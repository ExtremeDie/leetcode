**Example 1:**

<pre style="display: block;">Input: nums = [4,3,2,3,5,2,1], k = 4

```

**Example 2:** 

<pre style="display: block;">Input: nums = [1,2,3,4], k = 3

```

**Constraints:** 

- `1 <= k <= nums.length <= 16`
- `1 <= nums[i] <= 10^4`
- The frequency of each element is in the range `[1, 4]`.

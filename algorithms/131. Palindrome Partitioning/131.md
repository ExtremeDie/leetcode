# [131. Palindrome Partitioning](https://leetcode.com/problems/palindrome-partitioning/description/)

Given a string `s`, partition `s` such that every <div aria-expanded="false" data-headlessui-state="" id="headlessui-popover-button-:rt:">substring of the partition is a

**palindrome**. Return all possible palindrome partitioning of `s`.

**Example 1:**

```
<pre style="display: block;">Input: s = "aab"
Output: [["a","a","b"],["aa","b"]]
```

**Example 2:**

```
<pre style="display: block;">Input: s = "a"
Output: [["a"]]
```

**Constraints:**

-   `1 <= s.length <= 16`
-   `s` contains only lowercase English letters.
